``qct_initial.xyz``
===================

This file contains the exact Cartesian phase point generated by
:ref:`ensemble qct harmonic <kw_ensemble_qct>` before the first force
evaluation. It is overwritten whenever a new harmonic QCT phase point is
initialized.

The file uses extended XYZ format with ``pbc`` and ``Lattice`` metadata and
the properties::

  Properties=species:S:1:pos:R:3:mass:R:1:vel:R:3

Positions are in Angstrom, masses are in atomic mass units, and velocities are
in Angstrom/fs. The header also records the random seed and sampling
temperature. It can therefore be used directly as ``model.xyz`` for
``ensemble qct phase_point`` and is the preferred reactant reference for QCT
trajectory post-processing.
