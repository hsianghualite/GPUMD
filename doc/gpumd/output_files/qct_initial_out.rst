``qct_initial.out``
===================

This file records the harmonic normal-mode sample generated by
:ref:`ensemble qct harmonic <kw_ensemble_qct>`. It is overwritten whenever a
new harmonic QCT phase point is initialized.

The comment header contains the random seed, sampling temperature, zero-point
energy setting, phase-sampling setting, and the reaction-mode index. The
comma-separated data columns are::

  mode,frequency_THz,active,energy_eV,phase_rad,Q_sqrt_amu_A,P_sqrt_eV

``frequency_THz`` is an ordinary frequency in THz; the initializer converts it
to angular frequency with ``2 pi`` when constructing the phase point.
``Q_sqrt_amu_A`` is the sampled mass-weighted normal coordinate and
``P_sqrt_eV`` is its conjugate momentum in GPUMD natural units. Inactive modes
have zero sampled energy, phase, coordinate, and momentum.

Together with :ref:`qct_initial.xyz <qct_initial_xyz>`, this file makes the
random initial condition of each QCT replica reproducible and auditable.
